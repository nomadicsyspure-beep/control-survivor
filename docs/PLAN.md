# 컨트롤뱀서 기획 메모

## 방향
- 주인공은 인간형 격투 소년(261103melbourne 저장소 hero3d: 블렌더 3D → 8방향 렌더 → 96px · 24색 · 1px 외곽선 도트).
- 중심은 **손맛**: 근접 펀치 콤보 + 원거리 장풍 조금, 타격감·회피감을 아주 좋게.
- 탄막과 보스 패턴이 주가 되고, 몹은 적지만 단단하고 역할이 있다. 수백 마리 쓸어 담는 도파민은 별도 모드(나중에).
- 화면은 세로·가로 둘 다. 화면 짧은 변에 같은 세계 크기(340)가 보여서 어느 쪽이든 위험 거리가 같다.

## 조작
- **한 손 모드(기본)**: 이동만. 붙으면 펀치 콤보가 자동, 조금 먼 적에게 장풍이 가끔 자동.
- **두 손 모드(테스트)**: 왼손 이동(화면 왼쪽 절반), 오른손 공격·회피·장풍 버튼. PC는 WASD + J(공격) K(회피) L(장풍).

## 손맛 시험장 (지금)
- 콤보 3단: 잽 → 스트레이트 → 마무리(앞으로 쑥 들어가며 크게 날림). 앞쪽 부채꼴 안의 적을 모두 친다. 마무리 뒤엔 숨 고르기.
- 타격감: 히트스톱, 화면 흔들림, 하얀 번쩍임, 밀려남, 찌그러짐, 불꽃·파편, 데미지 숫자 팝, 마무리 타는 속도선 + 화면 당김 + 진동.
- 경직 게이지: 계속 때리면 무너진다(별, 받는 피해 ×1.5). 때리면 몹이 쏘려던 것도 끊긴다.
- 회피(두 손): 짧은 무적 대시. 탄이나 돌진이 닿기 직전에 피하면 **반격 찬스**: 잠깐 느려지고 다음 공격이 바로 마무리 타.
- 몹: 슬라임(쫓아옴) · 박쥐(거리를 두고 조준탄, 웨이브 6부터 부채꼴) · 골렘(단단, 빨간 길 예고 뒤 돌진). 5웨이브마다 보스(사방 탄 → 조준 산탄 3연발 → 돌진 → 졸개).
- 설정: 캐릭터 보기(동작 6개 · 8방향 회전) + 손맛 조절(히트스톱 · 흔들림 · 밀려남 배율, 이 기기에 저장).
