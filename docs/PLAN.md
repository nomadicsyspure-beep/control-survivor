# 컨트롤뱀서 기획 메모

## 방향
- 주인공은 인간형 격투 소년(261103melbourne 저장소 hero3d: 블렌더 3D → 8방향 렌더 → 96px · 24색 · 1px 외곽선 도트).
- 중심은 **손맛**: 근접 펀치 콤보 + 원거리 장풍 조금, 타격감·회피감을 아주 좋게.
- 탄막과 보스 패턴이 주가 되고, 몹은 적지만 단단하고 역할이 있다. 수백 마리 쓸어 담는 도파민은 별도 모드(나중에).
- 화면은 세로·가로 둘 다. 화면 짧은 변에 같은 세계 크기(340)가 보여서 어느 쪽이든 위험 거리가 같다.

## 조작
- **한 손 모드(기본)**: 이동만. 붙으면 펀치 콤보가 자동, 조금 먼 적에게 장풍이 가끔 자동.
- **두 손 모드(테스트)**: 왼손 이동(화면 왼쪽 절반), 오른손 공격·회피·장풍 버튼. PC는 WASD + J(공격) K(회피) L(장풍).

## 손맛 시험장 (지금)
- 콤보 3단: 잽 → 스트레이트 → 마무리(앞으로 쑥 들어가며 크게 날림). 앞쪽 부채꼴 안의 적을 모두 친다. 마무리 뒤엔 숨 고르기.
- 타격감: 히트스톱, 화면 흔들림, 하얀 번쩍임, 밀려남, 찌그러짐, 불꽃·파편, 데미지 숫자 팝, 마무리 타는 속도선 + 화면 당김 + 진동.
- 경직 게이지: 계속 때리면 무너진다(별, 받는 피해 ×1.5). 때리면 몹이 쏘려던 것도 끊긴다.
- 회피(두 손): 짧은 무적 대시. 탄이나 돌진이 닿기 직전에 피하면 **반격 찬스**: 잠깐 느려지고 다음 공격이 바로 마무리 타.
- 몹: 슬라임(쫓아옴) · 박쥐(거리를 두고 조준탄, 웨이브 6부터 부채꼴) · 골렘(단단, 빨간 길 예고 뒤 돌진). 5웨이브마다 보스(사방 탄 → 조준 산탄 3연발 → 돌진 → 졸개).
- 설정: 캐릭터 보기(동작 6개 · 8방향 회전) + 손맛 조절(히트스톱 · 흔들림 · 밀려남 배율, 이 기기에 저장).

## 스킬 · 필살기
- 한 손 모드는 조건이 맞으면 자동, 두 손 모드는 버튼 (PC: U 회오리 · I 어퍼 · O 지진 · 스페이스 필살).
- **회오리 발차기** (6초): 제자리에서 빙글 세 바퀴, 둘레 82를 세 번 친다. 마지막은 밀어냄. (자동: 가까이 3마리 이상)
- **돌진 어퍼** (5초): 순식간에 붙어서(잔상) 위로 올려쳐 **띄운다**. (자동: 100~230 떨어진 적)
- **지진 내려찍기** (9초): 뛰어올라 쾅 → 충격파, 둘레 150 적을 띄우고 기절. (자동: 4마리 이상 또는 보스)
- **필살기 백열권** (20초): 연출 → 범위 175 안 적들을 붙잡고 순간이동하듯 마구 두들김(1.25초) → 마지막 대폭발(띄우기 + 화면 섬광). (자동: 4마리 이상 또는 보스)
- 띄우기: 적이 공중에 떴다가 떨어지면 먼지 (공중에선 꼼짝 못 함).
- **필살기 연출 (설정에서 고르기)**: 컷인(비스듬한 띠 + 큰 주인공 + 기술 이름) · 줌인(화면 확 당김 + 빨려 드는 선) · 영역 전개(금빛 원이 펼쳐지고 밖은 어둡게, 원 안 적은 붙잡힘) · 암전(세상이 까맣게, 주인공 하양·적 빨강 실루엣) · 없음 · 돌아가며.
- 설정 "쿨타임 없애기 (테스트)": 스킬·필살기를 계속 써 볼 수 있게.

## 제스처 모드 (한 손, 시험)
- 끌기 = 이동 (붙으면 펀치 콤보 자동). 스킬은 자동이 아니라 제스처로.
- 톡(0.2초 안에 안 움직이고 떼기) = 회오리 발차기
- 휙(0.23초 안에 45px 넘게 긋기) = 돌진 어퍼, 그은 방향 ±45° 안의 가장 가까운 적에게 (없으면 그 방향으로 쑥)
- 꾹(제자리에서 0.28초 넘게 누르고 있기) = 기 모으기: 0.35초 장풍 · 0.95초 지진 · 1.7초 필살. 떼는 순간 나간다. 쿨타임이면 한 단계 아래로. 모으는 동안은 못 움직인다.
- 기 모으기 고리: 단계마다 색(파랑 장풍 · 주황 지진 · 빨강 필살)과 기술 이름이 주인공 위에.
